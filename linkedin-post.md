## Suggested post copy (full — so anyone can know what this is)

> **I gave my AI coding agent a mobile design rulebook — and it's free and open source.**
>
> Every developer using AI to build apps has felt this: the AI writes beautiful web UI, but when it comes to mobile screens, it guesses. It puts buttons in the top corner where thumbs can't reach, builds lists that stutter, hides the back gesture, ships dark mode that fails contrast checks.
>
> That's not the model's fault — mobile has hard rules nobody taught it. Apple's Human Interface Guidelines, Material 3, safe areas, gesture conflicts, haptics, keyboard behavior, touch-target sizes, Dynamic Type, store asset requirements. Thousands of rules, scattered across docs.
>
> **So I collected them into one searchable skill: nativetap.**
>
> 📱 **What it is:** 461 curated mobile design rules across 42 domains, plus 40 prioritized "thumb rules" — as plain data files your AI coding agent (Claude Code, Cursor, Codex, Windsurf, Antigravity) reads and searches before writing any UI.
>
> What's inside:
> 🍎 Apple HIG + Material 3 component specs (exact sizes: bar heights, FABs, sheets)
> 🧩 Flutter, SwiftUI, and Jetpack Compose patterns — wrong way vs right way, with the why
> 👆 Gesture conventions with haptics pairing · safe areas for notch/Island/keyboard
> 🌗 Dark mode that passes contrast · motion specs with real durations
> ♿ Accessibility: VoiceOver recipes, 200% font scale, color-blind safety
> 📊 Charts, forms, error messages, onboarding, monetization/paywalls
> 🧴 visionOS spatial UI · home-screen widgets & watch complications · App Clips
> 💳 In-app purchases: StoreKit 2, pending transactions, refunds, restore
> 🚀 Store assets: every icon size, screenshot strategy, keyword rules
>
> ⚙️ Zero dependencies · pure CSV + a search script · works offline · MIT license
> ⭐ Star it: github.com/awaisdev5765/nativetap
>
> It's also stage 1 of a complete shipping pipeline:
> nativetap (design it right) → prism_doctor (audit the code) → shipcheck (audit the launch)
>
> If you build mobile apps with AI, try it — one git clone and your agent stops guessing.
