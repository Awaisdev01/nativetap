# X/Twitter thread

1/ AI agents can build an app in a day. They still ship web patterns to
phone screens. So I built nativetap — mobile-only design intelligence for
coding agents. 🧵

2/ What's inside: 40 Thumb Rules with exact numbers (44pt targets, contrast
in both modes, Dynamic Type at 200%), HIG + Material 3 specs, gestures with
haptics pairing, safe-areas in Flutter/SwiftUI/Compose, motion durations.

3/ 12 searchable domains, zero dependencies, works offline, SKILL.md format
— Claude Code, Cursor, Codex, Windsurf, Antigravity.

4/ The fresh part: CI fingerprints live HIG/M3 pages monthly and opens a
review issue when Apple or Google change something. Curated data with
receipts.

5/ It's stage 1 of a pipeline: nativetap (design) → promptguard (test the
AI features) → shipcheck (launch audit + store kit). All MIT, all free.

6/ Repo: https://github.com/awaisdev5765/nativetap — PRs adding verified
rows to the CSVs are the highest-value contributions.
